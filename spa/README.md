# Dr. Luan Navarro — SPA Export Kit

Pure React + Vite SPA, ready to deploy on Vercel.

## Local
```
npm install
npm run dev
```

## Build
```
npm run build
```
Output: `dist/`

## Deploy on Vercel
- Framework preset: **Vite**
- Build command: `npm run build`
- Output directory: `dist`
- `vercel.json` already includes the SPA rewrite so all routes serve `index.html`.
